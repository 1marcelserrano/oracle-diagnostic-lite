# Contribuir

Obrigado pelo interesse. Esta skill é open-source sob licença MIT.

## Como propor mudanças

1. Faça um fork e crie um branch a partir de `main`.
2. A fonte de verdade do comportamento é `skills/oracle-diagnostic-lite/SKILL.md`. Comece por lá.
3. Mantenha o frontmatter (`name`, `description`, `metadata`) intacto.
4. Use Conventional Commits (`feat:`, `fix:`, `docs:`…).
5. Abra um PR descrevendo o que muda e por quê.

## Princípios

- **Voz direta.** Frases curtas, voz ativa, zero floreio. Sem léxico inflado, sem paralelismo negativo. Termo proprietário aterrissa na 1ª menção.
- **Localiza, não resolve.** A skill aponta a frente onde a tensão se concentra e para na fronteira do diagnóstico. Mudanças que a façam prescrever, montar plano ou dar o "como" vão contra o princípio central — isso é o Diagnóstico Oracle completo.
- **Sem pricing.** Esta é a entrada grátis do funil. Nenhuma contribuição deve introduzir valores ou tabela de preço.
- **O Oracle é árbitro, não ferramenta.** O Creative Oracle™ nunca é descrito como "ferramenta" ou "assistente".
